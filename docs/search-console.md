# Search Console workflow (wardogs-cheats.net)

Use this when verifying the site in Google Search Console and submitting URLs.

## Domain property

1. Open [Google Search Console](https://search.google.com/search-console) and add a **domain** property for `wardogs-cheats.net` if it is not already there.

2. Under **Sitemaps**, submit: `https://wardogs-cheats.net/sitemap.xml`

3. Optional: after deploys with `INDEXNOW_KEY` set in the environment, the build can ping IndexNow using the same host.
